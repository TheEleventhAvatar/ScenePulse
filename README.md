## ScenePulse (new work)

`ScenePulse` is a **new, separate subsystem** built on top of https://github.com/img2threejs/img2threejs . It is *not* part of
the original image-to-3D pipeline — that pipeline (`forge/`, `grimoire/`, `integrations/`) is upstream
work by the img2threejs authors and remains untouched. The Text-to-Three.js system turns a
natural-language prompt into an interactive, animated Three.js scene through structured data only.

### Pipeline

```
Natural-language prompt
        ↓
LLM provider (provider-agnostic; deterministic mock included)
        ↓
TextSceneSpec  (structured JSON — never executable JavaScript)
        ↓
Deterministic validator  (text2threejs/spec/validate_text_scene_spec.py)
        ↓
Three.js scene generation  (frontend/scene_builder.js — data-driven interpreter)
        ↓
Interactive browser viewport  (orbit · select · transform gizmos)
        ↓
Data-driven timeline  (play · pause · seek · scrub · easing)
        ↓
Natural-language editing  (patches the existing spec & scene in place)
```

Key guarantees:

- **The LLM produces spec data, not code.** Nothing generated by a model is ever executed; the
  browser interprets validated JSON through deterministic builders.
- **Edits patch, they don't regenerate.** A follow-up instruction ("make it glossy black", "move the
  camera closer") produces a validated patch applied to the existing scene graph.
- **Runs without an API key.** The `MockLLM` provider ships five deterministic demo scenes.

### Run the demo

```bash
# 1. Export the validated demo specs from the Python mock provider (single source of truth)
python -m text2threejs.llm.export_demo_specs

# 2. Serve the frontend and open http://localhost:8000
cd text2threejs/frontend
python -m http.server 8000
```

Three.js r170 is vendored under `text2threejs/frontend/vendor/`, so the demo runs fully offline —
no CDN or network access required.

Then: pick or type a prompt → **Generate** → select objects, drag gizmos, press **Play**, scrub the
timeline, and try edits like *"make the watch rotate 360 degrees and move the camera closer"* or
*"make the pedestal glossy black"*. Shortcuts: `Space` play/pause, `W/E/R` move/rotate/scale,
`F` frame selection, `Home` reset camera, `Esc` deselect.

The flagship demo is a **cinematic product reveal** (futuristic watch on a reflective pedestal) with
key/rim/fill lighting, fog, ACES tone mapping, and hand-written GLSL effects: a Fresnel rim-glow
material, a holographic scanline material, and a dithered procedural gradient background.
